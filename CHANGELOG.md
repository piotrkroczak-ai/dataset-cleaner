## Versioning Convention

`vMAJOR.MINOR.PATCH`

- **MAJOR** — complete architectural revision
- **MINOR** — new feature part completed (aligns with roadmap parts)
- **PATCH** — bug fix, stabilization, or incremental improvement within a part

Each version is logged with the files changed, a short description, and a git commit reference in the internal version log.
